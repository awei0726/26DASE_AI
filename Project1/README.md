## 实验内容

使用 TF-IDF 提取文本特征，训练逻辑回归（Logistic Regression，LR）与多项式朴素贝叶斯（Multinomial Naive Bayes，NB）。通过五折交叉验证比较不同超参数下的准确率，选择最佳模型预测无标签测试集。

## 实验设置与结果

- 特征：默认 `TfidfVectorizer()`，两个模型使用相同配置；未额外进行停用词过滤、词干化或数据增强。
- 验证：`GridSearchCV(cv=5, scoring="accuracy")`。分类任务默认采用不打乱的分层五折划分，每折约 80% 的有标签数据用于训练、20% 用于验证。
- 防止泄漏：将向量化器与分类器放在同一个 `Pipeline` 中，每折仅在训练部分拟合词表和 IDF，再转换验证部分。
- 随机数种子：`SEED=42`，LR 设置 `random_state=42`；NB 无随机状态参数。固定 CSV 行顺序，保持交叉验证划分一致。
- 选模：依据五折平均准确率选择参数；默认 `refit=True` 会在全部有标签数据上重新拟合最佳模型，再用于测试集预测。

| 模型 | 搜索范围                                                           | 最佳参数                      | 五折平均准确率 | 标准差（原始小数） |
| ---- | ------------------------------------------------------------------ | ----------------------------- | -------------- | ------------------ |
| LR   | L2 下 `C ∈ {0.1, 1, 10, 100, 1000}`，以及无正则化；`max_iter=2000` | L2，`C=100`                   | 93.5125%       | 0.006738           |
| NB   | `alpha ∈ {0.1, 0.5, 1.0, 2.0}`，`fit_prior ∈ {True, False}`        | `alpha=0.1`，`fit_prior=True` | 92.7931%       | 0.006515           |

LR 搜索共 6 组参数、30 次折内拟合；NB 共 8 组参数、40 次折内拟合，不含各自最佳模型的全量重拟合。各组完整结果由笔记本中的 `cv_results_` 输出，包含 `mean_test_score`、`std_test_score` 和 `rank_test_score`。

LR 的最佳平均准确率高于 NB 约 0.7193 个百分点，因此最终选择 LR。两个模型在无标签测试集上的预测一致率为 94.67%，该数值是模型间的一致率，不是测试准确率。
